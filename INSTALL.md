# Установка и запуск «Сути» у себя

Пошаговая инструкция для Windows 10/11: от пустого компьютера до работающего сервиса в браузере. Для Linux и macOS отличия собраны в конце.

Сколько времени займёт: 20–40 минут, большая часть — скачивание библиотек и моделей (~11 ГБ).

## Что понадобится

| Что | Зачем | Где взять |
|---|---|---|
| Windows 10 или 11 | — | — |
| Python 3.11–3.13 | сервер и модели | [python.org](https://www.python.org/downloads/) — при установке отметьте «Add python.exe to PATH» |
| Node.js 18+ (лучше 20+) | сборка интерфейса и скачивание с YouTube | [nodejs.org](https://nodejs.org/) |
| Git | скачать проект | [git-scm.com](https://git-scm.com/) |
| Ollama | конспекты, чат, перевод, энциклопедия | [ollama.com](https://ollama.com/download) |
| Видеокарта NVIDIA, 6 ГБ памяти и больше | быстрая расшифровка | желательно; без неё всё работает на процессоре, но медленно |
| ~15 ГБ свободного места | библиотеки, модели, видео | — |
| Интернет | только для установки и видео по ссылке | дальше сервис работает без него |

Драйвер NVIDIA нужен свежий (версия 570 или новее): библиотеки собраны под CUDA 12.8. Отдельно ставить CUDA не нужно. ffmpeg тоже ставить не нужно — он приходит вместе с библиотеками.

Проверить, что всё на месте: откройте **PowerShell** (Пуск → «PowerShell») и выполните по очереди:

```powershell
python --version
node --version
git --version
ollama --version
```

Каждая команда должна напечатать номер версии. Если пишет «не является внутренней или внешней командой» — программа не установлена или не добавлена в PATH; переустановите её и откройте PowerShell заново.

## Шаг 1. Скачать проект

В PowerShell перейдите в папку, где будет лежать проект (например, `C:\dev`), и скачайте его:

```powershell
cd C:\dev
git clone https://github.com/WiverHome/sut.git
cd sut
```

Репозиторий закрытый: если git спросит вход, войдите аккаунтом GitHub, которому выдан доступ к проекту.

Должна появиться папка `C:\dev\sut` с папками `backend`, `frontend`, `extension`, `scripts`. Все следующие команды выполняются **в этой папке**.

## Шаг 2. Python-окружение и библиотеки

Создаём отдельное окружение `.venv`, чтобы библиотеки проекта не смешивались с остальными:

```powershell
python -m venv .venv
```

Ставим PyTorch. **С видеокартой NVIDIA:**

```powershell
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu128
```

**Без видеокарты** (только процессор):

```powershell
.\.venv\Scripts\python.exe -m pip install torch
```

Затем остальные библиотеки:

```powershell
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
```

Это самый долгий шаг установки (PyTorch с поддержкой видеокарты — около 2,5 ГБ). В конце должно быть `Successfully installed …` без красных ошибок.

Проверить, что видеокарта видна:

```powershell
.\.venv\Scripts\python.exe -c "import torch; print(torch.cuda.is_available())"
```

`True` — видеокарта будет использоваться; `False` — всё пойдёт на процессоре.

## Шаг 3. Собрать интерфейс

```powershell
cd frontend
npm install
npm run build
cd ..
```

В конце должно быть `✓ built in …`. Появится папка `frontend\dist` — её раздаёт сервер.

Предупреждение npm про установочные скрипты (`install-scripts`) можно не замечать. Только если сама сборка падает с ошибкой про esbuild — разрешите его и пересоберите:

```powershell
cd frontend
npm install-scripts approve esbuild
npm rebuild esbuild
npm run build
cd ..
```

## Шаг 4. Запустить Ollama

Ollama после установки обычно запускается сама (значок ламы в трее у часов). Проверить:

```powershell
ollama list
```

Должна напечататься таблица (пусть даже пустая). Если пишет, что не может подключиться, — запустите Ollama из меню Пуск и повторите.

## Шаг 5. Скачать модели

```powershell
.\.venv\Scripts\python.exe scripts\download_models.py
```

Скрипт скачивает в папку `data\models` четыре модели, всего ~8,6 ГБ:

| Модель | Для чего | Размер |
|---|---|---|
| Whisper large-v3-turbo | распознавание речи | 1,6 ГБ |
| bge-m3 | поиск по смыслу | 2,3 ГБ |
| bge-reranker-v2-m3 | точный порядок результатов поиска | 2,3 ГБ |
| Qwen3-4B-Instruct | конспекты, чат, перевод | 2,5 ГБ |

Каждые 10 секунд скрипт пишет, сколько скачано. Он качает многими потоками, поэтому работает и при медленном доступе к HuggingFace. Если загрузка прервалась — просто запустите команду снова: готовые части не перекачиваются.

В конце языковая модель подключается к Ollama под именем `qwen-instruct:4b`, и скрипт пишет `Модель qwen-instruct:4b подключена к Ollama`. Проверить:

```powershell
ollama list
```

В списке должна быть `qwen-instruct:4b`. После этого файл модели в `data\models\qwen3-4b-instruct` можно удалить — у Ollama своя копия (освободит 2,5 ГБ).

## Шаг 6. Запустить сервис

```powershell
.\start.ps1
```

Если PowerShell пишет, что выполнение сценариев отключено, запустите так:

```powershell
powershell -ExecutionPolicy Bypass -File .\start.ps1
```

Сервер готов, когда появится строка `Uvicorn running on http://127.0.0.1:8000`. Откройте в браузере **http://127.0.0.1:8000**.

Первые 20–40 секунд после запуска загружаются модели поиска — в шапке будет «Загружаю модели…». Когда там появится зелёная точка и «Офлайн · всё локально», всё готово.

Остановить сервер: в окне PowerShell нажмите `Ctrl+C`.

## Шаг 7. Первая лекция

1. На главной перетащите видеофайл (MP4, WebM, MOV, MKV) в рамку или вставьте ссылку на YouTube, RuTube, VK Видео, Vimeo и нажмите «Добавить».
2. На карточке лекции видно, что происходит: «Скачиваю видео» → «Распознаю речь» → «Конспект в очереди» → «Пишу конспект» → «Готово». После «Готово» лекция ещё переводится на второй язык — это тоже видно на карточке.
3. Искать можно, как только речь распознана — не дожидаясь конспекта.

Сколько ждать на видеокарте с 6 ГБ: час лекции распознаётся за 2–20 минут (зависит от видеокарты и речи), конспект — ещё 2–5 минут. На процессоре — в разы дольше.

## Расширение для браузера (по желанию)

Боковая панель «Сути» прямо на YouTube, RuTube и других сайтах с видео. Работает в Chrome, Edge, Яндекс Браузере, Vivaldi и других браузерах на Chromium.

1. Сервис должен быть запущен (шаг 6).
2. Откройте `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
3. Включите «Режим разработчика» (переключатель справа вверху).
4. «Загрузить распакованное расширение» → выберите папку `extension` в папке проекта.
5. Закрепите значок «Суть» (фиолетовая лупа) на панели браузера.

Откройте видео и нажмите значок — справа откроется панель.

## Если YouTube просит «подтвердите, что вы не робот»

После многих скачиваний подряд YouTube начинает отказывать без входа в аккаунт — на карточке лекции появится такая ошибка. Выгрузите вход из браузера, в котором вы вошли в YouTube:

1. Полностью закройте этот браузер (работающий браузер не даёт прочитать свои cookies).
2. Выполните (вместо `vivaldi` — `chrome`, `edge`, `firefox`, `opera` или `brave`):

   ```powershell
   .\.venv\Scripts\python.exe scripts\export_youtube_cookies.py vivaldi
   ```

3. Должно появиться «Вход в аккаунт найден». Откройте браузер снова и на карточке лекции нажмите «Повторить».

Берутся только cookies YouTube и Google, сохраняются в `data\youtube_cookies.txt` (в git не попадает) и используются только для ссылок YouTube. Яндекс Браузер для этого не подходит — войдите в YouTube в другом браузере.

## Проверка, что всё работает

При запущенном сервере выполните в **другом** окне PowerShell, в папке проекта:

```powershell
.\.venv\Scripts\python.exe scripts\smoke_test.py путь\к\видео.mp4 "о чём эта лекция"
```

Скрипт загрузит видео, дождётся обработки, покажет время каждого шага, конспект, оглавление, результаты поиска и ответ чата. Для уже загруженной лекции: `scripts\smoke_test.py --id <id лекции> "запрос"` (id — в адресе страницы лекции после `/lecture/`).

## Обновление

```powershell
git pull
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
cd frontend; npm install; npm run build; cd ..
.\start.ps1
```

Интерфейс после обновления нужно пересобрать (`npm run build`): `start.ps1` собирает его сам, только если папки `frontend\dist` ещё нет.

## Где лежат данные

Всё в папке `data` внутри проекта (в git не попадает):

| Что | Где |
|---|---|
| База лекций, расшифровок, поискового индекса | `data\sut.db` |
| Видео, звук, миниатюры | `data\videos\<id лекции>\` |
| Модели | `data\models\` |
| Вход в YouTube | `data\youtube_cookies.txt` |

Начать с чистого листа: остановите сервер и удалите `data\sut.db*` и `data\videos`. Модели при этом останутся.

## Настройки

Задаются переменными окружения перед запуском, например:

```powershell
$env:SUT_DEVICE = "cpu"
.\start.ps1
```

| Переменная | По умолчанию | Что это |
|---|---|---|
| `SUT_DEVICE` | `auto` | `cuda` — видеокарта, `cpu` — процессор; `auto` выбирает сам |
| `SUT_LLM` | `qwen-instruct:4b` | модель Ollama для конспектов, чата и перевода (например, `qwen3:8b` после `ollama pull qwen3:8b`) |
| `SUT_OLLAMA` | `http://127.0.0.1:11434` | адрес Ollama |
| `SUT_WHISPER` | `data\models\faster-whisper-large-v3-turbo` | модель распознавания речи; на процессоре быстрее `small` или `medium` (скачаются сами) |
| `SUT_EMBED` | `data\models\bge-m3` | модель векторов для поиска |
| `SUT_RERANK` | `data\models\bge-reranker-v2-m3` | модель-«судья»; если её нет, поиск работает без неё |
| `SUT_DATA` | `data` | где хранить базу и видео |
| `SUT_MODELS` | `data\models` | где лежат модели |
| `SUT_YT_COOKIES` | `data\youtube_cookies.txt` | файл входа в YouTube |

## Частые проблемы

**Порт 8000 занят** (`error while attempting to bind on address … 8000`). Сервис уже запущен в другом окне — откройте http://127.0.0.1:8000 или закройте то окно. Запустить на другом порту:

```powershell
.\.venv\Scripts\python.exe -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8001
```

**В шапке «Модели поиска не загрузились».** Модели не скачаны или скачаны не до конца — запустите шаг 5 ещё раз, затем перезапустите сервер.

**В шапке «Без конспектов».** Не запущена Ollama или в ней нет модели. Выполните `ollama list` (шаг 4); если `qwen-instruct:4b` нет — повторите шаг 5. Поиск и расшифровка работают и без неё.

**Ollama не может скачать модели** (`connectex: An attempt was made to access a socket…`). Ollama закрыта брандмауэром. Это не мешает: скрипт из шага 5 скачивает модель сам и подключает её к Ollama без выхода Ollama в интернет.

**Расшифровка очень медленная.** Проверьте, что видеокарта видна (`True` в шаге 2) и в подсказке значка в шапке написано «видеокарта». На ноутбуке подключите зарядку: от батареи видеокарта работает медленнее. Закройте игры и другие программы, занимающие видеопамять.

**Скачивание с HuggingFace стоит на месте.** Прервите `Ctrl+C` и запустите шаг 5 снова — загрузка продолжится с того же места.

**Видео по ссылке не скачивается.** Текст ошибки на карточке подскажет причину. Часть роликов Vimeo доступна только после входа в аккаунт — такие надёжнее скачать самому и загрузить файлом.

**«В видео не найдено речи».** В ролике только музыка или речь очень тихая. Проверьте, что в видео слышна речь.

## Linux и macOS

Всё то же самое, с такими отличиями:

- Python в окружении: `.venv/bin/python` вместо `.\.venv\Scripts\python.exe`.
- PyTorch на Linux с видеокартой — та же команда с `--index-url …/cu128`; на macOS — просто `pip install torch` (вычисления на процессоре).
- Строки `nvidia-cublas-cu12` и `nvidia-cudnn-cu12` в `backend/requirements.txt` нужны только на Windows; на macOS их можно убрать из файла перед установкой.
- Вместо `start.ps1`:

  ```bash
  cd frontend && npm install && npm run build && cd ..
  .venv/bin/python -m uvicorn app.main:app --app-dir backend --host 127.0.0.1 --port 8000
  ```

## Для разработки

Интерфейс с мгновенным обновлением при правке кода: запустите сервер (шаг 6), затем в другом окне

```powershell
cd frontend
npm run dev
```

и откройте http://localhost:5173 — запросы к серверу на порт 8000 пересылаются сами.
