# Суть — поиск по видеолекциям по смыслу

Загрузите видеолекцию или вставьте ссылку на YouTube/Vimeo. Сервис распознает речь, построит оглавление с таймкодами, напишет конспект и выделит ключевые термины. Поиск находит нужный момент, даже если в лекции сказано другими словами, и сразу перематывает видео туда.

Работает **полностью на вашем компьютере**: распознавание речи, поиск и конспекты — локальные модели, интернет нужен только для первой загрузки моделей и для видео по ссылке. Лекции на русском и английском; можно искать по-русски в английской лекции и наоборот.

## Возможности

- **Загрузка** файлов MP4, WebM, MOV, MKV или ссылок на YouTube, RuTube, VK Видео, Vimeo (через yt-dlp; часть роликов Vimeo отдаётся только после входа в аккаунт); звук извлекается автоматически.
- **Расшифровка** речи (Whisper large-v3-turbo), время каждой фразы с точностью до секунды.
- **Перевод расшифровки** локальной моделью (английская лекция → русский, русская → английский) с переключателем «оригинал / перевод» на странице лекции, в субтитрах и в расширении; поиск идёт и по оригиналу, и по переводу.
- **Поиск по смыслу** по одной лекции или по всему курсу сразу. В выдаче — фрагмент текста, таймкод и переход к этому моменту.
- **Плеер** с субтитрами, расшифровкой рядом с видео (текущая фраза подсвечена, по клику — перемотка).
- **Оглавление** из разделов и подразделов с таймкодами, **конспект** и главные выводы.
- **Ключевые термины** с определениями и моментом, где о них говорится.
- **Вопрос-ответ**: чат отвечает по содержанию лекции (или всего курса) и даёт ссылки на моменты видео.
- **Энциклопедия курса** — все понятия из всех лекций: определения, переход к моменту в каждой лекции, связанные понятия и объяснение по материалам курса.
- **Справка** — как пользоваться сервисом и частые вопросы (страница «Справка» в шапке).
- **Расширение для браузера**: боковая панель «Сути» прямо на YouTube, RuTube, VK Видео, Vimeo и других сайтах с видео — оглавление, расшифровка и поиск, клик перематывает видео на самой странице. Для нового видео — кнопка «Обработать в «Сути».

## Как устроен поиск

1. Текст лекции режется на куски по ~30 секунд с перекрытием, каждый превращается в вектор моделью **bge-m3** (понимает русский и английский).
2. Параллельно работает поиск по словам (**BM25** по основам слов) — он ловит точные термины и имена.
3. Списки объединяются, и лучшие 30 кандидатов заново упорядочивает модель-«судья» **bge-reranker-v2-m3**: она читает запрос и фрагмент вместе.
4. Внутри найденного куска выбирается самая близкая к запросу фраза — к её началу ведёт таймкод.

Оглавление: лекция делится на смысловые блоки там, где сильнее всего меняется тема (по векторам соседних кусков). Затем локальная языковая модель (Qwen3-4B-Instruct через Ollama) озаглавливает блоки и группирует их в разделы.

## Установка и запуск

**Полная пошаговая инструкция — в [INSTALL.md](INSTALL.md)**: что поставить, как проверить каждый шаг, настройки, обновление и частые проблемы.

Коротко, для Windows с видеокартой NVIDIA (нужны Python 3.11+, Node.js 18+, Git и [Ollama](https://ollama.com)):

```powershell
git clone https://github.com/WiverHome/sut.git
cd sut
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install torch --index-url https://download.pytorch.org/whl/cu128
.\.venv\Scripts\python.exe -m pip install -r backend\requirements.txt
cd frontend; npm install; npm run build; cd ..
.\.venv\Scripts\python.exe scripts\download_models.py
.\start.ps1
```

Откройте http://127.0.0.1:8000. Скрипт `download_models.py` скачивает модели (~8,6 ГБ) в `data/models` и подключает языковую модель к Ollama; прерванную загрузку можно запустить снова. Без видеокарты всё работает на процессоре, но медленнее.

## Расширение для браузера

Работает в Chrome, Яндекс Браузере, Edge и других браузерах на Chromium (нужна версия Chrome 114 и новее).

1. Запустите сервис (`.\start.ps1`).
2. Откройте в браузере `chrome://extensions` (в Яндекс Браузере — `browser://extensions`).
3. Включите «Режим разработчика» (переключатель справа вверху).
4. Нажмите «Загрузить распакованное расширение» и выберите папку `extension` в папке проекта.
5. Закрепите значок «Суть» (фиолетовая лупа) на панели браузера.

Откройте лекцию на YouTube или RuTube и нажмите значок — справа откроется панель. Если видео уже обработано, в ней будут план, текст и конспект; клик по таймкоду или фразе перематывает видео на странице. Если ещё нет — кнопка «Обработать в «Сути»».

Видео находится по адресу страницы: `youtu.be/…`, `youtube.com/watch?v=…&list=…`, встроенный плеер — это одно и то же видео. Работает и плеер, встроенный в страницу другого сайта (iframe).


## Если YouTube просит «подтвердите, что вы не робот»

После многих скачиваний подряд YouTube начинает отказывать без входа в аккаунт. Выгрузите вход из своего браузера:

1. Закройте браузер, в котором вы вошли в YouTube, полностью.
2. В папке проекта выполните (вместо `vivaldi` — `chrome`, `edge`, `firefox`, `opera`, `brave`):

```powershell
.\.venv\Scripts\python.exe scripts\export_youtube_cookies.py vivaldi
```

3. Должно появиться «Вход в аккаунт найден». Откройте браузер снова и на карточке лекции нажмите «Повторить».

Берутся только cookies YouTube и Google, они сохраняются в `data/youtube_cookies.txt` (в git не попадает) и используются только для ссылок YouTube.
